# Issue tracker

Issues e especificações vivem no GitHub Issues de Pedrocrlx/EarnIt.
Usar a CLI gh, indicando --repo Pedrocrlx/EarnIt.

- Publicar: gh issue create --title "..." --body-file <ficheiro>
- Consultar: gh issue view <número> --comments
- Listar: gh issue list
- Etiquetar: gh issue edit <número> --add-label <etiqueta>
- Comentar: gh issue comment <número> --body-file <ficheiro>
- Fechar: gh issue close <número>

Consultar também as etiquetas ao analisar uma issue.

PRs as a request surface: no.
