# Domain docs

Estrutura single-context: CONTEXT.md na raiz e decisões em docs/adr/.

Antes de explorar, ler CONTEXT.md e os ADRs relevantes.
Se não existirem, prosseguir; serão criados quando houver termos
ou decisões de domínio a registar.

Usar o vocabulário do glossário nas especificações e no código.
Assinalar explicitamente propostas que contrariem um ADR existente.
